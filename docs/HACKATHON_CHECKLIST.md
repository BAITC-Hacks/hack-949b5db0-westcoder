- 26.09.2026: Рок Ли (`HK-68220`), Сацуки Кусакабэ (`HK-76268`), Альфонс Элрик (`HK-53108`).
- 27.09.2026: Рок Ли (`HK-68220`), Нобара Кугисаки (`HK-16628`).

Сейчас подробные причины исключения доступны в воронке. Перед защитой полезно сделать разницу между датами заметнее, чтобы жюри сразу видело причину ухода конкретного профиля.

## Что ещё требует внимания

1. **Краткость объяснения для карточки.** После объединения с изменениями команды `frontend/app.js` показывает именно `explanation` из API. Источник теперь единый, но `backend/explanations.py` возвращает развёрнутый текст из нескольких предложений. Следующий шаг — сократить основное объяснение до 1–2 предложений, оставив подробные факты в `reasons` и модальном окне.
2. **Индивидуальность по смыслу.** Разные цены делают тексты различными технически. Сильная защита дополнительно показывает разные факты, полезные именно для запроса: стиль, подтверждённые пожелания, лимит часов или состав услуги. Не выдавать рекламные заявления профиля за независимую оценку качества.
3. **Строгая повторяемость с внешним API.** Изменения команды сохраняют и успешный результат, и резервный результат после сбоя. Обычный повтор не обращается к провайдеру повторно; кнопка «Повторить AI-анализ» явно разрешает обновить неудачное решение и может изменить порядок. Эти переходы проверены тестами с подменой транспорта; перед защитой остаётся проверить работу с действующим ключом.
4. **Задержка AI.** Внешние embeddings имеют сетевой таймаут 6 секунд. Разные запросы больше не удерживают общую блокировку во время сетевого вызова; одинаковые запросы разделяют один вызов, что проверено тестами. Общая задержка под реальной нагрузкой не измерена. Дополнительный AI-разбор описания допускает 12 секунд ожидания провайдера; он не нужен для обязательного запроса подбора. Живые вызовы с действующим ключом пока не проверены.
5. **Проверка с чистого окружения.** Локальные тесты уже проходили, но перед передачей жюри нужно повторить инструкции README в новом checkout без `.tools`, `.cache` и локального `.env`. Само приложение не требует npm-пакетов.
